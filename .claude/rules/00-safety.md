# Safety & engagement rules

- **Defense-only**: automation catalog and attack scripts target the local / operator-owned deployment only.
- Do not build or improve third-party attack tooling framed as offensive against others.
- Do not commit secrets, unseal passphrases, private keys, or live admin tokens.
- Prefer fail-closed behavior for enforcement; document any intentional accept-risk as prod-delta.
- Respect dual-control for erasure, kill switch, permanent bans, and other high-blast actions.
