# How to read evaluation reports

**Diátaxis quadrant:** Explanation. **Audience:** evaluators and adopters.

A credible report describes its exact artifact, policy, topology and case set.
It includes failed setup, errors and skipped cases instead of hiding them from
the denominator. Challenge, deny and allow remain separate outcomes.

Human controls need their own results, including keyboard, assistive technology,
shared networks and coherent browsers. Resource overhead and recovery friction
belong beside detection observations. No catalog can establish universal coverage.

The complete Rust replacement has no qualified full-system report here yet.
Named automation services are research subjects, not measured blocked vendors.
See the [evaluator guide](../start-here/evaluator.md).
