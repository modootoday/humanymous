# Observatory evidence boundaries

**Diátaxis quadrant:** Explanation. **Audience:** evaluators and interface developers.

An observatory makes observations and decision traces easier to inspect. Its
view must distinguish synthetic demonstrations from live measurements and
detector results from enforced origin outcomes.

Display missing, truncated and unavailable inputs explicitly. Avoid labels that
identify a visitor as malicious from a score. Diagnostics need access controls
and minimization; raw bodies and credentials do not belong in routine views.

The Rust interface and browser integration are not release-qualified. Earlier
screenshots have been retired from the new documentation rather than presented
as current runtime evidence. See [reporting](transparency-report.md).
