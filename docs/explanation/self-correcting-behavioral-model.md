# Behavioral model limits

**Diátaxis quadrant:** Explanation. **Audience:** researchers and accessibility reviewers.

Behavioral aggregates can describe an interaction, but sparse movement, low
event counts or slow input do not establish automation. Accessibility tools,
keyboard navigation and ordinary reading produce different interaction patterns.

Model updates need bounded inputs, poisoning controls, rollback and measured
human impact. No automatic self-improvement or validated Rust learning loop is
claimed here. Frozen scoring policy remains unchanged during migration.

Recovery must never require motor richness or speed. Treat model results as
scoped evidence within a declared deployment, not a universal identity test.
See [accessible recovery](../help/challenge-accessibility.md).
