# Project components and boundaries

**Diátaxis quadrant:** Explanation. **Audience:** evaluators and integrators.

Core computes detection results. Gate applies request enforcement at an edge.
Browser collection and accessible Pass recovery provide additional inputs and
interaction. Audit records evidence continuity. Administration manages local
policy and destructive operations under separate authorization.

An adapter connects application lifecycle events to the shared authority. It
does not become another scoring engine, nor does it automatically acquire raw
TLS or body-transform capability. An observatory visualizes a result; its display
does not prove that an origin request was blocked.

These responsibilities are being migrated to Rust. Individual component tests
and full deployment acceptance remain separate. See [status](../reference/production-vs-reference.md).
