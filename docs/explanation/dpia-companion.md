# Privacy assessment companion

**Diátaxis quadrant:** Explanation. **Audience:** privacy reviewers.

Observation-based enforcement can affect access and process personal data even
when it retains only aggregates or pseudonyms. Purpose limitation, necessity,
retention and accessible recovery need deployment-specific review.

Separate durable enforcement audit from sampled analytics. Declare loss and
overflow rather than promising unlimited durability. Do not collect raw forms,
passwords, clipboard contents or screenshots by default. Consider shared devices,
network changes and assistive technology when assessing erroneous outcomes.

The Rust deployment and erasure path remain unqualified. This companion is not
a completed impact assessment or legal certification. Start with the
[data inventory](../reference/data-processing-inventory.md).
