# Security disclosure

**Diátaxis quadrant:** How-to. **Audience:** security researchers.

Follow the repository's [security policy](https://github.com/modootoday/humanymous/blob/main/SECURITY.md)
and the public [security contact](../.well-known/security.txt). Test only systems
you own or are explicitly authorized to assess. This project does not authorize
probing unrelated deployments.

Provide the affected revision, deployment profile, minimal synthetic reproducer,
expected boundary and observed result. Avoid real visitor data, credentials and
private keys. Keep sensitive details out of public issues while the report is
being assessed.

A report or dependency scan is not proof that all other vulnerabilities are
absent. See [security evidence](security-audit.md) for reporting limits.
