# Standards and project proposals

**Diátaxis quadrant:** Reference. **Audience:** protocol reviewers.

The [Draft v0 collection](../standards/draft-v0/index.md) is a project proposal,
not an adopted standard or submitted Internet-Draft. Its exact wire encoding,
independent vectors and interoperability evidence remain incomplete.

Existing standards provide building blocks with distinct scope:
[HTTP Message Signatures](https://www.rfc-editor.org/rfc/rfc9421.html) authenticates
covered message components; [HTTP digests](https://www.rfc-editor.org/rfc/rfc9530.html)
describe content integrity; [robots.txt](https://www.rfc-editor.org/rfc/rfc9309.html)
publishes crawler preferences. None establishes a natural person's presence or
grants origin authorization by itself.

Do not substitute the project draft for an existing standard. Consult its
[preparation record](../standards/draft-v0/process/preparation.md) for maturity gates.
