# Support and licensing

**Diátaxis quadrant:** Reference. **Audience:** adopters and contributors.

humanymous is an Apache-2.0 reference project. Consult the repository's
[license](https://github.com/modootoday/humanymous/blob/main/LICENSE) for its terms.
This documentation does not add a service-level agreement, warranty or
production-support commitment.

File ordinary project questions in the repository after removing credentials,
visitor identifiers and private logs. Send security-sensitive reports through
the [disclosure process](security-disclosure.md). Access problems on a deployed
site belong to that site's operator.

The Rust migration and adapter targets remain subject to
[qualification](production-vs-reference.md). Project licensing alone does not
establish standards-venue contribution or intellectual-property clearance.
