# Glossary

**Diátaxis quadrant:** Reference. **Audience:** all readers.

| Term | Meaning |
| --- | --- |
| Observation | A fact captured at a stated boundary, with provenance and completeness |
| Capability | An observation or lifecycle hook actually available in a deployment |
| Decision | A request-bound allow, challenge or deny outcome; input errors remain distinct |
| Gate | The enforcement edge between clients and an origin |
| Origin | The application service behind the enforcement path |
| Core | Detection computation, without assuming edge enforcement |
| Pass | Accessible recovery/challenge design; motor richness and speed are not access requirements |
| Fail closed | Refuse protected processing when a required safety condition cannot be established |
| Dual control | Independent authorized approval for a destructive administrative action |
| Coherent-browser ceiling | The limit of distinguishing consistent real-browser automation from legitimate use |
| Qualification | Evidence for an exact version, topology and capability set |
| Project draft | A developing proposal without implied external adoption or conformance |
