# Read a decision view

**Diátaxis quadrant:** How-to. **Audience:** reviewers of diagnostic interfaces.

Start with the artifact, policy revision and capture topology. Read missing or
truncated observations before interpreting a score. Check whether the view
describes a detector result or an actual enforced request.

Then examine request binding and origin effect. Avoid inferring visitor intent
from a label. Export only minimal redacted evidence. No current Rust interface
tour or screenshot is presented as operationally verified.
See [review preparation](detection-observatory.md).
