# Review optional device-lab scope

**Diátaxis quadrant:** How-to. **Audience:** authorized browser researchers.

No Rust virtual-device lab is qualified by this branch. Do not treat a simulated
device event or a browser trust flag as proof that a natural person acted.

If a device pilot is needed, define an owned isolated target, synthetic content
and the exact observation under study. Compare keyboard, assistive-technology
and ordinary browser controls. Preserve the coherent-browser ceiling and never
make device richness an access requirement. See [accessible recovery](../help/challenge-accessibility.md).
