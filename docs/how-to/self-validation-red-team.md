# Prepare owned-lab self-validation

**Diátaxis quadrant:** How-to. **Audience:** authorized evaluators.

Restrict every target to the project's isolated owned deployment. Name the
artifact, topology, synthetic accounts, workload limits and stopping conditions.
The Rust full-lab integration is not yet qualified.

Require Docker topology for full enforcement evidence. Include legitimate users
and coherent-browser controls. Record setup failures, errors and skips along
with decisions and origin effects; do not tune frozen policy to fit a result.
See [evaluation rules](../reference/red-team-rules-of-engagement.md).
