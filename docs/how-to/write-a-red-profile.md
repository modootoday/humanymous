# Specify a defensive regression case

**Diátaxis quadrant:** How-to. **Audience:** authorized lab contributors.

Name an isolated owned target and the precise boundary being exercised. Declare
required capabilities, synthetic inputs, expected decision and origin effect,
resource limits and stopping conditions.

Include a legitimate control and explicit error/skip handling. Preserve all
attempts in the evidence ledger. Do not add third-party targets or ship attack
artifacts in defender packages. Rust catalog integration and full Docker runs
remain acceptance gates.
See [catalog evidence](../reference/red-team-catalog.md).
