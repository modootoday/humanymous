Why a game? This is humanymous Pass — shown only when a session is scored ambiguous. It is built so a real person clears it effortlessly while an automated agent, reasoning over a static screenshot, cannot: the answer is not in the page — it is whatever placement your intuition finds, verified by re-simulating the physics on the server. This page is a non-blocking research surface: attack it, study it. It raises the cost of automation; it does not claim to stop it.
