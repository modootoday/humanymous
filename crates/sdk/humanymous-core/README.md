# humanymous-core

Shared observation contracts, behavior transforms, model inference, scoring,
request integrity, challenge primitives and resource watermarks. These bounded
contexts share one safe Rust package; they do not supply native provider proof,
operating-system custody or human verification by themselves.

The default library has no browser engine, native SDK or runtime service
dependency. The qualification feature enables the explicitly selected canonical
performance example; it grants no runtime authority. Tests use the workspace's
test support during migration. Publication and full product qualification remain
pending.
