## Decision rules

1. Search hits are candidates. Confirm the actual semantics, trust boundary,
   consumer and controlling requirement before assigning a violation.
2. Review SRP by cohesive responsibility, dependency/target and consumer reason.
   Neither length, file count, a small facade nor a standard lib.rs/mod.rs proves
   a defect. No directory-only rewrite, forwarding-only fragmentation or generic
   utility consolidation is an automatic remedy.
3. Require standard Cargo targets/layout, humanymous-* package names and Rust
   naming conventions; distinguish package, library identifier, binary, public
   wire ID and historical oracle names. Preserve public bytes unless separately
   authorized. Root alone integrates shared manifests and lock/toolchain.
4. All new implementation/tests remain Rust 1.99.1/edition 2024. Inspect embedded
   executable strings and generated templates as code, regardless of extension.
   The three C# exceptions are exactly NativeBinding.cs, HumanymousMiddleware.cs
   under adapters/dotnet/src/Humanymous.Native and adapters/dotnet/pilot/Program.cs.
   Upstream generated declarations need source/tool provenance and retirement
   conditions. Existing foreign oracles are explicit debt, not new-code waivers.
5. Authored prose/comments remain English. Preserve exact raw evidence, upstream
   quotations, literal UI titles and intentional multilingual fixtures. Bounded
   language indicators cannot establish complete English conformance; inline
   comments, fences and unrecognized languages require independent review.
6. Preserve detection freeze, one scoring owner, fail-closed required evidence,
   audit-before-effect, independently authorized dual control and motor/speed-free
   accessibility. No third-party probing, sandbox weakening or false T4 claims.
7. Review unsafe allowances against the exact accepted boundary and provenance;
   forbid broad suppression as a substitute for a fix. Safe API construction and
   resource ownership are part of the review even without unsafe code.
8. Bind notices and package contents to exact source and actual artifacts.
   Known-notice source correctness is distinct from complete dependency licensing,
   registry ownership, package installation and publication readiness.

### Model migration design review

Root requested independent review of the model-training-correction draft. The
bounded record parser/shared-feature slice is viable without kernel, RNG, sink,
lifecycle, dependency or production activation changes. Require explicit label
0/1 and behavior presence, bounded input/metadata, finite raw floating fields and
finite extracted vectors. Reuse behavior::features::extract; derive human status
from the validated label, not a separately supplied contradictory boolean.
JSON source/cohort labels are assertions, not authenticated provenance.

Before kernel/gate/lifecycle implementation, resolve these P1 contracts:

- Go uses one seeded stream for normal initialization and epoch shuffles;
  warm-start skips initialization draws. Fixtures must cover coupled cold/warm
  draw order and intermediate math, or root must accept a compatibility delta.
  Pin the historical oracle version from actual tool/fixture provenance before
  exporting vectors; this review does not establish an executed Go tool version.
- The legacy cohort map contains only observed humans. Require an externally
  configured cohort set, sufficient humans for every cohort, bot support and
  explicit denominators; an all-bot holdout cannot pass vacuously.
- Stable timestamp sorting preserves ties, not strictly future-only evaluation.
  Report missing/zero/tied boundary times. Anchor timestamp zero alone does not
  guarantee train-only placement when the anchor fills the cut; define membership
  and leakage policy explicitly.
- Failed/abandoned CHALLENGE and solved Pass are weak/poisonable labels. Retain
  legacy mapping fixtures without promoting them to ground truth; quarantine and
  independently review production-derived admission, quotas and anomalies.
- Hash, signature verification, parse, schema and predictor must consume the
  same bounded owned bytes. Do not reproduce legacy path rereads. External key
  policy and lab-only stage/active/previous identity and epoch remain explicit;
  callbacks execute outside configuration locks and never activate production.

These are source-grounded design blockers, not executed training findings. The
legacy train, gate, oracle and bundle sources were read independently; no Go or
Rust workload was launched. Required 29 legacy responsibilities remain open for
their own implementation and actual qualification. Verdict: ready for the
bounded parser slice, needs-work for kernel/gate/lifecycle.
