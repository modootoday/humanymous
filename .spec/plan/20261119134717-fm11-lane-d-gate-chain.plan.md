# FM11 lane D gate chain

## Goal

Port the remaining legacy `internal/gate/gates.go` gates of the Go
`ServeHTTP` chain at 981d25c (verdict token, upgrade, agent auth, PAT,
WebAuthn, sweep) and the attestation floor audit, and record the rest of
row `internal/gate/gates.go` truthfully. Lane D of the Step 3 bulk delivery
mode of `plan:root/20261117142053`; base is `claude/fm11-bulk` 0ceb8c35.

Detection freeze: no score, weight, threshold, hard-rule predicate, verdict
band or signal ID changes. The gates enforce existing kernel decisions only
(owner decision B1: exact-parity ports against Go-captured goldens, never
regenerated, frozen engine reused). Gate default modes, ban-store
provisioning, the public listener (B01), metrics and the kill switch stay
owner-pending.

## Steps

- [x] Slice 1, gate kernel: `gateway::gates` holds the gate decisions as pure
  functions over the existing token, credential, fan-out and sweep kernels,
  replayed case by case against the Go capture
  `tests/fixtures/gateway/gates-go-golden.json` (`gateway::gates::tests`).
  Each Go-to-Rust difference is a named fix-up in the replay and documented
  in the module: uppercase verdicts; a neutral Web Bot Auth keyid recorded as
  presented; a fan-out observation the bounded registry cannot admit
  withholds the upgrade without a record; an enforcing sweep detector that
  cannot count is an error (fail closed). The settings_runtime monitor-mode
  cases of the verdict-token, recon-sweep and attestation-floor gates are
  mapped at kernel level.
- [x] Slice 2, served-path composition: `gateway::application::gates` runs
  agent auth, PAT, WebAuthn (fan-out cap), upgrade and sweep in Go order for
  proxied requests, after session authorization and admission and before
  scoring, each behind an opt-in `Application::install_*` capability that
  the service binary does not install. `Application::gc` sweeps the
  installed sweep detector and fan-out tracker. Pinned by
  `gateway::tests::gates`; SoT section "Credential, upgrade and sweep gates"
  in `sot:root/runtime-application`.
- Not composed, recorded as gaps on row `internal/gate/gates.go`: the
  verdict-token gate (nothing on the served path mints `hmn_vt`) and the
  attestation floor audit (no route presets, so no attested route). Row
  stays `partial`; no row moves to `ported_unit` in this lane.
