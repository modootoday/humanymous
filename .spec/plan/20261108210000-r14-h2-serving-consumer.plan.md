# R14 H2 serving consumer — plan delta

Brief: Plan row R14 requires complete H2 frame/HPACK/per-stream capture **and
server**. Capture I0 (`20e05fd4`) observes only. R13 `CapturedRequest` is H1-only.
Unconditional `required.original_h2` → 422 (N06 interim) blocks G1 until a
same-owner serving consumer exists. This delta specifies that consumer against
**live** architecture; no H1→H2 inference; detection freeze.

## 1. Problem

Without a gateway H2 serve path, `original_h2` cannot be observation-gated the
way `raw_tls` already is via `client_hello()`. Product cells stay non-green;
observation modules alone must not lift N06.

## 2. Vocabulary / IDs

| ID | Meaning |
| --- | --- |
| R13 | TLS/H1 `CapturedRequest` — unchanged, H1-only |
| R14 | TLS/H2 serving consumer — separate owner path |
| N06 | Fail-closed `original_h2` until same-owner observation **and** hosted validation for product/readiness claims |
| I0 | DATA-only ingress observation (`observe_h2` / `project_h2`) — not serving |

## 3. Decision rules

R14-D1. **Separate consumer.** Do not widen R13 `CapturedRequest` to accept `h2`.
Add `CapturedH2Request` (or equivalent enum arm) that requires negotiated ALPN
`h2` after the same `PendingHandshake` → `Connection` ownership model as R13.

R14-D2. **Reuse capture, retain body in gateway.** Feed decrypted bytes through
the existing `Connection::read_plaintext` → `http2::Capture` path. Capture still
retains no body values (N05). The gateway serving owner accumulates unpadded
DATA for the selected stream and refuses length mismatch vs Capture metadata.

R14-D3. **First profile bounds.** Single client stream id `1` only; no push;
trailers refuse (existing `observe_h2`); body ≤ gateway `MAX_BODY`; frame/
header budgets match network-capture N04/N05. Multiplexing beyond stream 1 is
out of this slice.

R14-D4. **Minimal server wire.** After handshake, write connection SETTINGS
(including `INITIAL_WINDOW_SIZE` ≥ body budget). ACK client SETTINGS. Respond
on stream 1 with HPACK `:status` HEADERS and optional DATA + `END_STREAM`.
No h2c/H3. Do not advertise ALPN `h2` then parse as H1.

R14-D5. **Capability gate.** Replace unconditional `original_h2` → 422 with the
same-owner pattern used for `raw_tls`: require live TLS owner + successful
`observe_h2` (Ended stream, body count match, no trailers) for the request's
method/authority/target/body length. Missing/failed observation stays 422.

R14-D6. **Honesty / N06 split.** Observation-gated authorize is allowed once
R14-D1–D5 land. Configuration readiness, matrix `required_unavailable`, and
`pass_product*` remain false until actual hosted H2 binding + owner integration
are measured. Cap=1 pure green ≠ product green. No scoring changes.

R14-D7. **Idle / origin boundaries.** Do not call `check_h1_idle` on H2.
Recheck `remaining()` and stream-1 Ended/body invariance before decision, after
durable audit, and before origin write. Ambiguous failure poisons the epoch.
