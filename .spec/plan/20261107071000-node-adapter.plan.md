## Rust owner integration delta

No Cargo root changes were made. Add the decision listener to the existing Rust
service composition root (not a second scoring engine). Read exact wire in
[[sot:root/adapter-service-contract]] and structural JSON schemas under
adapters/contracts. Use a duplicate-key-rejecting UTF-8 parser with bounded HTTP
body, independently credentialed permission-restricted IPC, real peer identity,
tenant/origin/installation/adapter/revision scope, atomic replay store, canonical
base64/length/SHA256 recomputation and existing RIT/security authority. Require
route capability readiness and durable audit before ALLOW. Return only the seven
bound response fields. No TCP/admin fallback. Node uses no custom signature or
score clone and cannot supply original TLS/H2 or authenticated capture facts.
Actual service integration is a release blocker, not a successful mock test.

## CI interface and measured state

Package: adapters/node/package.json, @humanymous/node 0.1.0-experimental.1.
No runtime npm dependencies. Exact development versions and integrity hashes are
in its own package-lock.json. CI runs npm ci, npm test, npm run test:pilot,
npm run test:bun, npm run typecheck, npm audit --audit-level=low and
npm pack --dry-run --json in adapters/node. OIDC workflow owner receives this
interface; no publishing was performed. engines.node >=22 is an installation
floor; measured tuples are only the two host pilots above, not release support.
Package archives include only source/declarations, README, LICENSE, metadata and
capability descriptor; no tests, node_modules, private evidence or lab attackers.

Initial Node test execution found Express replay did not reach body-parser;
replaced private stream-state manipulation with public bounded Readable body
method delegation, reran binary and JSON body-parser pilots on both runtimes.
All successful authority responses in these tests come from mock conformance
fixtures. No Go files were changed, so Go package tests are not applicable.
No host runner is used as Docker completion authority.
