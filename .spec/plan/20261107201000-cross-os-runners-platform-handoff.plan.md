runner actor.rs has a separate Job/token/account quarantine. A merged package's
crate-level forbid(unsafe_code) cannot be bypassed by a nested allow: Root must
review the narrow module lint boundary without broadening unsafe permission.
No new FFI or permanent private helper package is authorized by this handoff.
Owned File/CreatedDirectory/InteractiveAttempt and private fields are custody,
not publicly forgeable booleans; wire identity remains UnverifiedIdentityClaim.
CreatedDirectory is a locator-only obligation, not atomic creation identity.

Windows dependencies are cfg-scoped: bridge windows-sys0.61.2 and
windows-permissions0.2.4; native-security winsafe0.0.29, keyring-core1.0.1,
windows-native-keyring-store1.1.0; Unix rustix process; zeroize separate.

runner also uses getrandom/sha2 and its own windows-sys features. Unifying package
features can silently expand the default graph; do not infer safe defaults from
workspace/all-features checks. Root owns manifests, common lock and graph changes.
