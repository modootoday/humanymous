This is an unmodified origin application. It knows nothing about bot detection — the humanymous Gate reverse proxy sits in front of it, injects the detection bundle into this HTML on the fly, scores every session, and enforces the verdict at the edge before a request ever reaches here.

Protected routes

/login, /checkout and /admin are marked strict in the Gate route policy — a bot verdict is denied at the edge; the origin is never contacted.

Origin cloaking

The origin accepts traffic only when it carries the rotating X-Hmny-Origin-Auth token the proxy attaches, so a direct hit that bypasses the proxy is refused (HTTP 421).
